## Có thể làm tiếp (chỉ khi có yêu cầu)

- Dọn luồng game khi đóng tab (xem `DEBUG_LOG` mục 1).
- IPC: token xác thực, giới hạn đường dẫn `screenshot`.
- Lưu `tabs.txt` bằng cách ghi tạm rồi đổi tên.
- Kiểm tra proxy bằng cổng thật của game thay vì kết nối thử chung chung.
- Kiểm thử chịu tải nhiều tab; thử trên Termux.
